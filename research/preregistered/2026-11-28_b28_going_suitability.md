# Preregistration - Batch 28 individual going suitability (written 28 Nov 2026 ~3:45pm Brisbane, before any run)

History holds going only as categories (Good, Soft, Heavy, Synthetic; Firm merged into Good). No ordering is assumed.
Measure (point in time, earlier runs only, each engine's own surprises): gspec = (sum of surprises in today's category) / (runs in that
category + 3) - gen x n_cat / (n_cat + 3), gen = the horse's shrunk mean surprise over all earlier runs (k = 3). Synthetic is its own
category (turf and synthetic never pooled). Not tuned after seeing results.
Tests: (1) individual: does gspec predict the run's surprise beyond general form (gen, last-3 mean) and the existing going record
(g_rec)? 2023-24 and 2025-26 separately. (2) engine: REPLACE g_rec with gspec in Engine v2.3 and in the consolidated engine (national
harness, refit mode R, windows A and B). Same decision rule as the Batch 27 distance preregistration: gain >= 0 in both windows with the
lower 95% bound above -0.0005, else not adopted. Descriptive extras (not decision inputs): winners-on-a-surface vs consistent
over-performers on it; going x distance (sprint/middle/staying) heterogeneity.
