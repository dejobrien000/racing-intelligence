## What needs fixing before the real run can work unattended

1. **WebFetch approval (blocker).** In an unattended scheduled session, each TAB racecard URL triggers a permission
   request. Nobody is there to answer it, so it times out (~5 min) and fails. The 24 Nov 20:53Z capture worked, most
   likely because someone was there to approve it. Fix: allow WebFetch for api.beta.tab.com.au in this task's
   permission settings, or switch the task to automatic approval if the organisation allows it. This run did not
   change any settings.
2. daily_build.py should exit with a clear "no racecards captured" message instead of a traceback when the raw file has
   no RACE lines.
3. Test design: when prospective/prerace/<D> is moved aside, INDEX.csv must be isolated as well, or Engine v2 and export
   fail.
